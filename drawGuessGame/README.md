# 你画我猜

一个在聊天室里多人同玩的画猜游戏：玩家轮流当画手，在画板上画出题目，其他人通过聊天室聊天猜词。

- 全员参与：所有进房用户自动加入游戏，游戏中进房者先观战、下局自动加入。
- 轮流作画：按进房顺序轮换画手，每人都有机会出题。
- 三选一出题：画手从 3 个随机题目（同分类）中选一个，或等待 10 秒自动随机。
- 猜词判定：直接在聊天室输入答案即可，支持「答案是xx」「我猜xx」等常见说法（忽略空格、全半角、大小写与标点）。
- 防剧透：绘画阶段聊天中出现答案相关文字时，对非画手自动打码。
- 计分：第一个答对 3 分、第二个 2 分、其余 1 分，画手每收获一个答对者 +1 分。
- 60 秒绘画回合（可配），全部答对或超时即结算；每人当一次画手后整局结束，展示最终排名。
- 原生 Canvas 画板：钢笔 / 马克笔 / 喷枪 / 橡皮、调色盘、粗细调节、撤销与清空，笔迹实时同步。
- 词库沿用聊天室旧画猜房的 `config/draw_words.json`（53 个分类、上千词条），可直接复用。



## 本地运行

```bash
cd drawGuessGame
go run . -addr :8091
```

首次运行尚未配置接入凭证时提供页面服务；按[接入教程](../接入教程.md)完成建房、配置 `config/integration.json` 与公钥后，即可从聊天室插件房进入联机。

## 配置说明

`config/plugin_config.json`（运行配置）：

| 字段 | 默认 | 说明 |
| --- | --- | --- |
| `addr` | `:8091` | 监听地址 |
| `instanceId` | `draw-1` | 实例标识（排障用） |
| `pubkey` | `config/plugin_jwt.pub.pem` | 聊天室验签公钥 |
| `wordsPath` | `config/draw_words.json` | 词库文件路径 |
| `roundSeconds` | `60` | 绘画回合时长（秒） |
| `selectSeconds` | `10` | 选题时长（秒） |
| `resultSeconds` | `8` | 回合结算展示时长（秒） |
| `totalRounds` | `0` | 单局总回合数，`0` 表示每人当一次画手 |
| `maxPlayers` | `12` | 单局最大参与人数 |

命令行参数优先于配置文件：`-round-seconds`、`-select-seconds`、`-total-rounds` 等可覆盖，环境变量见 `main.go`。

- 页面资源**自动选择**：启动目录存在 `./public` 就用磁盘文件（本地开发改页面刷新即生效，不用重启）；不存在则用编译时 `//go:embed` 打进二进制的资源（发布只带单个可执行文件，无需 public 目录）。
- 部署时若不想带 `public/`，把二进制和 `config/` 放同一目录启动即可；改页面需重新编译（`sh shell/build.sh`）。

## 日志

启动脚本 `shell/run.sh` 会把标准输出/错误追加到同目录日志（`weiqi.log` / `drawGuess.log`）。
程序每分钟检查一次日志大小，**超过 200KB 时自动裁掉更早的内容，只保留最后约 120KB**（按行对齐，不会出现半行）。

- 调整上限：`LOG_MAX_KB=500 ./shell/run.sh` 或启动参数 `-log-max-kb 500`
- 关闭裁剪：不传 `LOG_FILE` 环境变量（例如手动 `go run .` 时默认不裁剪）
- 裁剪不会生成 `.1/.2` 备份文件，避免磁盘占用翻倍；需要长期留存请接入外部日志收集

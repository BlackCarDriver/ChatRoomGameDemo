# 围棋 / 五子棋

一个可在聊天室里双人对弈、多人观战的小游戏，支持 19 路围棋和 15 路五子棋。

- 进入游戏后可以观战，点击黑白空座位加入对局，两人就座后即可开始。
- 围棋支持提子、停一手和认输；五子棋以先连成五子者获胜。
- 默认每回合有 60 秒思考时间，超时视为停一手；对局中会显示剩余时间和本局用时。
- 支持头像与头像框、聊天气泡、全屏，以及结束后再来一局。
- 聊天消息带提示音（`bibi.mp3`），**落子有棋子音效**（`chess.mp3`），快速连落从头播、重连不重放历史手。
- 页面按 1024×768（4:3）固定画布整体等比缩放，任意窗口尺寸内容比例一致；聊天区占满侧栏剩余高度。
- 棋手离座或离开房间时对局中止，不计算胜负。

- 页面资源**自动选择**：启动目录存在 `./public` 就用磁盘文件（本地开发改页面刷新即生效，不用重启）；不存在则用编译时 `//go:embed` 打进二进制的资源（发布只带单个可执行文件，无需 public 目录）。
- 部署时若不想带 `public/`，把二进制和 `config/` 放同一目录启动即可；改页面需重新编译（`sh shell/build.sh`）。

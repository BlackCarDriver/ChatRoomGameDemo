# 围棋 / 五子棋 / 象棋

一个可在聊天室里双人对弈、多人观战的小游戏，支持 19 路围棋、15 路五子棋和 9×10 象棋。

- 进入游戏后可以观战，点击空座位加入对局；上座后点「准备」，**双方都准备后自动开始对局**，再点一次可取消准备；对局结束自动回到未准备状态。
- 顶部玩法切换（围棋 / 五子棋 / 象棋），棋盘上方以醒目楷体标注当前玩法；对局进行中不可切换。
- **围棋**：固定 19 路，支持提子、停一手和认输；双方连续停手后按中国规则数子判定胜负。
- **五子棋**：固定 15 路，先连成五子者获胜；棋盘已满判和棋。
- **象棋**：固定 9 列 × 10 行，红方先手（座位 1），支持全部子力走法（车炮马象士将兵）、蹩马腿、塞象眼、炮架、将帅照面禁止、将军/解将/将死/困毙判定；点己方棋子选中，可走点会高亮，点终点走子；无停一手，**思考超时判负**。
- 默认每回合有 60 秒思考时间，超时视为停一手（象棋为判负）；对局中会显示剩余时间和本局用时。
- **悔棋**（三种棋通用）：回退自己刚下的一手，无需对手同意；只能在自己落子后、对手落子前使用，对局结束后不可用；**每局每方上限 3 次**，已用次数显示在对应座位头像下方（0 次不显示）。
- 支持头像与头像框、聊天气泡、全屏，以及结束后再来一局。
- 聊天消息带提示音（`bibi.mp3`），**走子有棋子音效**（`chess.mp3`），快速连走从头播、重连不重放历史手。
- 页面按固定设计画布整体等比缩放：**横屏 1024×768（4:3）左右分栏；竖屏 540×960（9:16）纵向布局**——棋盘占满宽度，席位区收紧，**观战成员与游戏内聊天并排两列**。由视口宽高比自动切换，运行时旋转即时重排。
- 棋手离座或离开房间时对局中止，不计算胜负。

- 页面资源**自动选择**：启动目录存在 `./public` 就用磁盘文件（本地开发改页面刷新即生效，不用重启）；不存在则用编译时 `//go:embed` 打进二进制的资源（发布只带单个可执行文件，无需 public 目录）。
- 部署时若不想带 `public/`，把二进制和 `config/` 放同一目录启动即可；改页面需重新编译（`sh shell/build.sh`）。

## 日志

启动脚本 `shell/run.sh` 会把标准输出/错误追加到同目录日志（`weiqi.log` / `drawGuess.log`）。
程序每分钟检查一次日志大小，**超过 200KB 时自动裁掉更早的内容，只保留最后约 120KB**（按行对齐，不会出现半行）。

- 调整上限：`LOG_MAX_KB=500 ./shell/run.sh` 或启动参数 `-log-max-kb 500`
- 关闭裁剪：不传 `LOG_FILE` 环境变量（例如手动 `go run .` 时默认不裁剪）
- 裁剪不会生成 `.1/.2` 备份文件，避免磁盘占用翻倍；需要长期留存请接入外部日志收集
